# Project Hub Display

tolong buatkan web site menngunakan htlm css dan javascript, web ini untuk melihat proyek yang sedang berjalan dan sudah selesai

untuk tampilan webnya buatkan page awal layar dashboard yang bisa menampilkan proyek terbaru berdasarkan proyek dimulai

untuk detil dashboard buatkan list proyek dengan nama proyek dan tanggal proyeknya, buatkan disain nya berupa card 5x7 

dan buatkan menu side bar di sebelah kiri dengan pilihan open proyek dan closed pryek

saat kita klik open proyek akan menampilkan proyek yang sedang berjalan, gunakan disain yang sama seperti disain yang di dashboard

saat kita klik closed proyek akan menampilkan proyek yang sudah selesai, gunakan disain yang sama seperti disain yang di dashboard
